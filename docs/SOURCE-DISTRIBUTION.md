# Source distribution / 公開ソースの構成

The public source snapshot is generated by scripts/prepare-public-source.mjs from an explicit file manifest in scripts/public-source-files.json. Run it from the development directory; it creates a new directory and never overwrites an existing one:

```powershell
node scripts/prepare-public-source.mjs reports/public-source-candidate
```

Commit the generated candidate directory, not the entire historical development folder. No git remote is created and nothing is pushed by the script. Use repository name **standrig-connect**, display name **StandRig Connect**. Candidate generation is source preparation, not publication.

公開用にはC#/C++ソース、組み込み評価コード、評価コードの生成元アダプタ・共通トラッキングコード、テスト、ビルド手順、ライセンスを含めます。package.jsonはネイティブ版向けのスクリプトに切り替えます。依存バージョンとロックファイルは維持します。

旧Web試作のUI・サーバー、内部計画・検証履歴、非公開の将来計画、モデル素材、画像、個人設定、reports、workspace、node_modules、生成バイナリは含めません。モデルを同梱する場合は別途権利と内容の確認が必要です。

The script validates allowed paths, rejects symlinks, scans source for common private-path/credential/embedded-asset markers and verifies the committed evaluator hash. SHA256SUMS.json records every exported file. This is a bounded source check, not a guarantee that arbitrary secrets can be detected automatically. Review the manifest and changes before publishing.

Build the generated directory and run the documented tests before a first push. CI covers the base Windows build and core tests, not camera hardware, OBS reception or inference/model redistribution. No binary release is generated.
